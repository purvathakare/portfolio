## 🚀 How to Run & View Locally

1. Open `index.html` directly in any modern browser (Chrome, Edge, Firefox, Brave, Safari).
2. Or launch a local server:
   ```powershell
   python -m http.server 8000
   ```
   and navigate to `http://localhost:8000`.
